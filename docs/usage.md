# Nav-AI 功能使用说明

## 界面总览

| 区域 | 说明 |
| --- | --- |
| 顶栏 | 站点标题、搜索框、主题切换、数据管理、管理模式开关 |
| 侧边栏 | 分类树导航（桌面端常驻，移动端为抽屉菜单，点右上角 ✕ 或按 Esc 关闭）；底部为「分类管理」与「设置」 |
| 主区域 | 当前分类下的站点卡片列表；管理模式右侧有「排序」「添加站点」 |

## 浏览站点

- 点击侧边栏任意分类，查看该分类下的站点；点击「全部分类」查看全部
- 点击站点卡片，会在**新标签页**打开对应网站；同时记录本地访问次数与时间
- 切换分类后页面会回到顶部；再次打开站点时会停留在上次浏览的分类
- 「最近打开 / 最常访问」在产生访问记录后出现在侧边栏，分别按访问时间、访问次数排序（数据只存在本机）
- 「全部分类」视图可点击分组标题左侧的箭头折叠 / 展开分组；排序与批量模式下会强制展开
- 「未分类」仅在存在未归类站点时出现：侧边栏底部有独立入口，同时在「全部分类」视图末尾以单独分组展示

## 搜索站点

- 点击顶部搜索框，或按快捷键 **`/`** 快速聚焦
- 输入关键词后按**名称、所属分类、标签、描述、网址**实时过滤全部站点
- 结果按相关性排序（名称前缀 > 名称包含 > 分类名 > 标签 > 描述 > 网址），每张结果卡片会标注所属分类
- 结果是「命令面板」式列表：按 **`↑` / `↓`** 切换选中项，按 **`Enter`** 在新标签页打开当前项
- 按 `Esc` 或清空输入框即可返回分类浏览（弹窗打开时 `Esc` 优先关闭弹窗）

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `/` | 快速聚焦搜索框 |
| `↑` `↓` | 在搜索结果间切换选中项 |
| `Enter` | 打开当前选中的搜索结果 |
| `Esc` | 关闭弹窗 / 关闭移动端菜单 / 退出排序模式 / 清空搜索 |
| `Tab` | 在弹窗内循环移动焦点；站点卡片操作按钮可聚焦后使用 |

## 添加站点

1. 点击顶栏右侧「**管理**」按钮进入管理模式
2. 三种入口任选：
   - 分组标题旁悬浮出现的「**＋**」按钮 → 添加到该分类（触屏设备常显）
   - 分组末尾的「**添加站点**」虚线卡片
   - 右下角悬浮的「**＋**」按钮（默认进入当前视图分类）
3. 填写表单：
   - **名称**（必填）
   - **网址**（必填，可省略 `https://`，会自动补全）
   - **描述**（可选，卡片上展示；留空时显示域名）
   - **图标地址**（可选，**留空将按设置自动抓取该网站图标**）
   - **标签**（可选，逗号分隔，最多 8 个；参与搜索并显示在卡片描述下方）
   - **置顶**（可选，置顶站点排在所属分类最前；普通浏览时生效，排序模式下按手动顺序展示）
   - **所属分类**（下拉选择，含子分类）
4. 点击「添加」完成

> 移动端（触摸屏）管理模式下，卡片右上角会常驻编辑/删除按钮，无需悬停。

### 批量添加（一次粘贴多个站点）

1. 打开「添加站点」弹窗，切换到「**批量添加**」
2. 选择「所属分类」（批量模式会把整批站点放进该分类）
3. 每行一个站点，支持三种写法：

   ```
   https://github.com
   GitHub https://github.com
   掘金|https://juejin.cn
   ```

4. 点击「批量添加」。名称可省略（默认用域名），**网址重复的条目会自动跳过**，因此可以反复粘贴整份清单而不产生重复；添加完成后底部提示条可在 **6 秒内撤销整批添加**

## 排序站点

1. 进入「管理」模式，点击主区右侧的「**排序**」按钮进入排序模式
2. 调整顺序：
   - **拖拽**：按住卡片拖到目标位置，卡片右侧出现落点指示；拖到**其它分组**的卡片上即等于把站点移动到该分类；拖到分组空白处可移入该分组（空分类也可接收）
   - **按钮**：每张卡片右上角的 `↑` / `↓`（键盘与触屏都可用，不会与其它分类的站点交换）
3. 按 `Esc` 或再次点击「完成排序」退出排序模式（排序结果会立即保存）

> 置顶站点在普通浏览时排在最前；进入排序模式后按手动顺序展示，此时 ↑↓ 与拖拽的结果和屏幕顺序完全一致。

## 编辑 / 删除站点

1. 进入「**管理**」模式
2. 鼠标悬停在站点卡片上（移动端直接可见），右上角出现按钮：
   - ✎ **编辑**：修改任意字段（含标签与置顶）后保存
   - 🗑 **删除**：确认后删除该站点

> 删除后屏幕底部会出现「已删除…」提示，**6 秒内可点击「撤销」**把站点还原回原位置。

## 批量管理站点

1. 进入「管理」模式，点击主区右侧的「**批量**」按钮
2. 点击卡片即可勾选 / 取消（也可以按 Tab 聚焦卡片后按空格键）；操作条会显示已选数量
3. 操作条提供：
   - **全选本页** / 取消全选：选中当前视图下的全部站点
   - **移动到分类…**：把选中的站点整体移动到某个分类（或「未分类」）
   - **删除选中**：整批删除，删除后同样可在提示条里一键撤销
4. 按 `Esc` 或再次点击「完成批量」退出批量模式

> 「排序」与「批量」两种模式互斥，进入其中一种会自动退出另一种并清空搜索。

## 分类管理

点击侧边栏底部「**分类管理**」打开管理面板：

- **操作入口**：桌面端悬停分类行（或键盘 Tab 聚焦）显示操作按钮；触摸设备常显
- **添加顶级分类**：点击「添加分类」，输入名称与图标（emoji，可留空）
- **添加子分类**：点击分类行「＋」（仅支持两级分类）
- **重命名**：点击 ✎，直接编辑名称与图标后回车保存
- **排序**：点击 ↑ / ↓ 调整同级顺序
- **删除**：点击 🗑 并确认；该分类下的站点会自动移入「**未分类**」，不会丢失；6 秒内可「撤销」恢复分类与站点归属

## 外观与设置

点击侧边栏底部「**设置**」打开面板（所有改动即时生效）：

| 设置项 | 说明 |
| --- | --- |
| 站点标题 | 顶栏左侧显示的文字，最多 24 个字符；同时会同步到浏览器标签与安装后的应用名 |
| 主题 | 跟随系统 / 浅色 / 深色（顶栏主题按钮同样可以循环切换） |
| 主色 | 6 套预设，会同步影响按钮、激活态、焦点环与背景氛围光 |
| 卡片密度 | 舒适 / 紧凑：紧凑模式缩小卡片内边距、图标容器与网格间距，一屏容纳更多站点 |
| 卡片描述 | 显示 / 隐藏：隐藏后卡片只保留名称与图标 |
| 站点图标来源 | 「直连优先」（先取站点自身 favicon，更少依赖第三方）、「服务优先」（先走 favicon.im，命中率更高）或「仅字母」（不请求任何外部图标，完全离线） |

## 安装到主屏（PWA）

站点已内置 PWA 支持：

- **桌面浏览器**（Chrome / Edge）：地址栏右侧会出现「安装」图标，点击即可作为独立应用打开
- **Android Chrome**：菜单 → 「添加到主屏幕」
- **iPhone / iPad Safari**：分享 → 「添加到主屏幕」

安装后即使断网也能打开（首次访问时会预缓存页面、样式与脚本；数据本就在浏览器本地）。发布新版本后，页面底部会提示「应用已更新」，点击「刷新」即可生效；未点击时当前页面继续使用旧版本，不会出现资源错乱。

## 主题切换

点击顶栏主题按钮（图标随模式变化：半圆=跟随系统 / 太阳=浅色 / 月亮=深色），在三种模式间循环切换：

**跟随系统 → 浅色 → 深色**

选择「跟随系统」时会自动匹配设备深浅色偏好；主题选择会被记住。

## 数据备份与迁移

点击顶栏「数据管理」图标（数据库图标）打开面板：

| 操作 | 说明 |
| --- | --- |
| 下载备份文件 | 导出全部数据为 JSON 文件 |
| 复制到剪贴板 | 复制 JSON 文本，便于粘贴保存 |
| 导出只读分享页 | 生成一份自包含 HTML（数据与样式全部内联、不请求任何外部资源、跟随系统深色），可直接发给他人或离线查看 |
| 导出浏览器书签 | 生成 Netscape 书签 HTML，可导入 Chrome / Edge / Firefox |
| 从文本导入 | 粘贴备份 JSON →「预览导入」→ 选择覆盖 / 合并 → 确认执行 |
| 选择备份文件 | 从本地 JSON 文件导入（同样先预览再确认） |
| 导入浏览器书签 | 选择浏览器导出的书签 HTML（Chrome / Edge：书签管理器 → 导出书签），先显示「新增 / 跳过 / 新建分类」预览，确认后按文件夹还原为分类并与现有数据**合并**（同网址自动跳过）；导入后可整批撤销 |
| 恢复默认演示数据 | 清空当前数据，回到初始示例 |

> 面板顶部会显示上次完整备份时间、本地占用 / 可用空间，以及浏览器是否授予持久化存储；超过 30 天未导出备份时，页面顶部会提示一次（关闭后 7 天内不再打扰）。

> 「覆盖导入」替换全部数据；「合并导入」按网址去重，并与现有分类按名称合并。预览会给出预计新增 / 跳过的站点数与新建分类数。

> 覆盖式导入、书签导入、批量添加与「恢复默认演示数据」执行后，底部提示条都会提供 **6 秒撤销**入口，点击即可完整还原操作前的数据；撤销类提示不会被「应用已更新」等通知顶掉。

> 旧版本导出的备份（`version: 1`）可以直接导入，会自动升级到当前数据结构。

> 数据保存在浏览器 localStorage 中，**清除浏览器缓存/站点数据会同时清除导航数据**，建议定期导出备份。

## 常见问题

**Q：站点图标没有显示？**
图标获取按「站点自身 favicon → 图标服务」依次尝试，个别站点可能被目标网络拦截，此时会自动显示彩色字母头像；也可以在编辑站点时手动填写图标地址（任意可访问的图片 URL），或在「设置」里把图标来源切换为「服务优先」。若希望完全不请求外部资源，可切换为「仅字母」。

**Q：如何修改站点标题「Nav-AI」？**
点击侧边栏底部「设置」，直接修改「站点标题」即可（即时生效）；也可以编辑 `src/store/data.js` 中 `defaultData()` 的 `settings.title` 后重新构建部署。

**Q：两个标签页同时打开，数据会互相覆盖吗？**
不会。任一标签页保存后，其它标签页会自动同步到最新数据。

**Q：导入的数据里有些站点不见了？**
所属分类不存在的站点会被自动归入「**未分类**」并在顶部给出提示，不会丢失；该分组会同时出现在侧边栏与「全部分类」视图末尾，搜索也仍能搜到。

**Q：换电脑或换浏览器后数据没了？**
数据仅存于当前浏览器。在新设备上打开「数据管理」→「导入数据」，导入之前导出的备份 JSON 即可。
