# Nav-AI 功能使用说明

## 界面总览

| 区域 | 说明 |
| --- | --- |
| 顶栏 | 站点标题、搜索框、主题切换、数据管理、管理模式开关 |
| 侧边栏 | 分类树导航（桌面端常驻，移动端为抽屉菜单，点右上角 ✕ 或按 Esc 关闭） |
| 主区域 | 当前分类下的站点卡片列表 |

## 浏览站点

- 点击侧边栏任意分类，查看该分类下的站点；点击「全部分类」查看全部
- 点击站点卡片，会在**新标签页**打开对应网站
- 「未分类」仅在存在未归类站点时显示在侧边栏底部

## 搜索站点

- 点击顶部搜索框，或按快捷键 **`/`** 快速聚焦
- 输入关键词后按**名称、描述、网址**实时过滤全部站点
- 按 `Esc` 或清空输入框即可返回分类浏览（弹窗打开时 `Esc` 优先关闭弹窗）

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `/` | 快速聚焦搜索框 |
| `Esc` | 关闭弹窗 / 关闭移动端菜单 / 清空搜索 |
| `Tab` | 在弹窗内循环移动焦点；站点卡片操作按钮可聚焦后使用 |

## 添加站点

1. 点击顶栏右侧「**管理**」按钮进入管理模式
2. 三种入口任选：
   - 分组标题旁悬浮出现的「**＋**」按钮 → 添加到该分类（触屏设备常显）
   - 分组末尾的「**添加站点**」虚线卡片
   - 右下角悬浮的「**＋**」按钮（默认进入当前视图分类）
3. 填写表单：
   - **名称**（必填）
   - **网址**（必填，可省略 `https://`，会自动补全）
   - **描述**（可选，卡片上展示；留空时显示域名）
   - **图标地址**（可选，**留空将自动抓取该网站图标**）
   - **所属分类**（下拉选择，含子分类）
4. 点击「添加」完成

> 移动端（触摸屏）管理模式下，卡片右上角会常驻编辑/删除按钮，无需悬停。

## 编辑 / 删除站点

1. 进入「**管理**」模式
2. 鼠标悬停在站点卡片上（移动端直接可见），右上角出现按钮：
   - ✎ **编辑**：修改任意字段后保存
   - 🗑 **删除**：确认后删除该站点

## 分类管理

点击侧边栏底部「**分类管理**」打开管理面板：

- **操作入口**：桌面端悬停分类行（或键盘 Tab 聚焦）显示操作按钮；触摸设备常显
- **添加顶级分类**：点击「添加分类」，输入名称与图标（emoji，可留空）
- **添加子分类**：点击分类行「＋」（仅支持两级分类）
- **重命名**：点击 ✎，直接编辑名称与图标后回车保存
- **排序**：点击 ↑ / ↓ 调整同级顺序
- **删除**：点击 🗑 并确认；该分类下的站点会自动移入「**未分类**」，不会丢失

## 主题切换

点击顶栏主题按钮（图标随模式变化：半圆=跟随系统 / 太阳=浅色 / 月亮=深色），在三种模式间循环切换：

**跟随系统 → 浅色 → 深色**

选择「跟随系统」时会自动匹配设备深浅色偏好；主题选择会被记住。

## 数据备份与迁移

点击顶栏「数据管理」图标（数据库图标）打开面板：

| 操作 | 说明 |
| --- | --- |
| 下载备份文件 | 导出全部数据为 JSON 文件 |
| 复制到剪贴板 | 复制 JSON 文本，便于粘贴保存 |
| 从文本导入 | 粘贴备份 JSON 后导入（**覆盖当前数据**） |
| 选择备份文件 | 从本地 JSON 文件导入 |
| 恢复默认演示数据 | 清空当前数据，回到初始示例 |

> 数据保存在浏览器 localStorage 中，**清除浏览器缓存/站点数据会同时清除导航数据**，建议定期导出备份。

## 常见问题

**Q：站点图标没有显示？**
图标自动抓取依赖第三方 favicon 服务，个别站点可能被目标网络拦截，此时会自动显示彩色字母头像；也可以在编辑站点时手动填写图标地址（任意可访问的图片 URL）。

**Q：如何修改站点标题「Nav-AI」？**
编辑 `src/store/data.js` 中 `defaultData()` 的 `settings.title` 后重新构建部署；或在浏览器控制台执行：
```js
const d = JSON.parse(localStorage.getItem('nav-ai-data-v1'));
d.settings.title = '我的导航';
localStorage.setItem('nav-ai-data-v1', JSON.stringify(d));
location.reload();
```

**Q：换电脑或换浏览器后数据没了？**
数据仅存于当前浏览器。在新设备上打开「数据管理」→「导入数据」，导入之前导出的备份 JSON 即可。
